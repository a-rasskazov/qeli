# Q03 — Панель: состояние и ошибки загрузки

Дата: 3 октября 2026. Статус: **IN_PROGRESS**.

Этот проход закрывает два дефекта страниц конфигурации и блокировок.
Полный раздел 03 ещё не завершён: остаются остальные страницы, поздние ответы,
ошибки фонового обновления, модальные окна и дополнительные keyboard/mobile пути.

## Q03-F001 — Незагруженная политика выглядела доступной для сохранения

При задержке или ошибке GET `/api/blocked/settings` поля оставались доступны,
а Save отправлял значения по умолчанию. Backend отклонял первоначальную запись
без `expected_revision`; фактическая перезапись конфигурации не воспроизведена.
UI скрывал границу между загруженными настройками и начальной заготовкой.

Исправлено: поля и Save блокируются до успешной загрузки настроек и ревизии,
параллельные загрузки/сохранения не допускаются. Ошибка остаётся видимой;
Reload повторяет запрос. Fieldset также блокирует клавиатурное редактирование.
На мобильном экране политики расположены последовательно.

## Q03-F002 — Отказ canonical defaults включал дублирующую JS-схему

Сбой GET `/api/config/defaults` не мешал Add profile: панель создавала профиль
из большого встроенного объекта. Эта копия могла расходиться с Rust defaults.
При повторной неудачной загрузке мог сохраняться ранее полученный шаблон.

Исправлено: JS-копия удалена; загрузка использует общий `apiFetch` и сбрасывает
старый шаблон. При отказе показано локализованное сообщение, Add заблокирован.
Просмотр и редактирование успешно загруженного конфига продолжают работать;
Reload восстанавливает добавление только после получения canonical template.

## Проверки

28 групп реальных JS-компонентов PASS. Три новые регрессии проверяют загрузку,
отсутствующую ревизию, retry, защиту от повторного Save и исчезновение fallback.
До исправления регрессия воспроизвела лишний POST; исходный лог сохранён.

В настоящем Edge: восемь сценариев, RU/EN × desktop/mobile × две страницы.
Проверены disable при загрузке/ошибке, retry, сохранение политики клавишей Enter,
создание canonical профиля клавишей Enter и сохранение его дополнительного поля.
Ошибок JS/ресурсов не было; восемь скриншотов сохранены и мобильный RU / desktop RU
визуально просмотрены. API — fixtures на локальном loopback; это UI-интеграция,
не подтверждение auth/HTTP persistence/сети настоящего сервера.

Статика: 11 шаблонов / 1154 RU строк. Native inputs не изменились; provenance
A/B прошёл без переобъявления сборок библиотек. Проверки Linux и SHA бинарника
зафиксированы в [evidence](../../../release/certification/evidence/q03-panel-load-20261003.json).

Первый Linux build не засчитан: нулевой mtime файлов архива позволил Cargo
переиспользовать старые include-объекты. Повторный build обновляет даты всех
исходных входов, проверяет новое сообщение в бинарнике и отличающийся SHA.
Первоначальный результат сохранён с `FAILED_STALE_EMBEDDED_ARTIFACT`.
Это исправление тестового стенда; работающие службы не заменяются.
